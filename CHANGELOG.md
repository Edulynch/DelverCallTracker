# Changelog

All notable changes to Delver Call Tracker will be documented in this file.

## 1.0.0 - 2026-05-06

- Initial addon structure for tracking Delver's Call - Midnight quests.
- Added compact filter UI for not taken, in progress, completed, and turned-in quests.
- Added TomTom/native waypoint support with multi-step routes through Silvermoon.
- Added turn-in waypoints for known quest NPCs.
- Added persistent selected filter, highlighted row, and active route restoration after reload.
- Added right-click row action to clear the addon waypoint and highlighted row.
