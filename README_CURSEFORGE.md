# Delver Call Tracker

**Delver Call Tracker** keeps your **Delver's Call - Midnight** progression clean, fast, and easy to follow.

Track every Delver's Call quest, filter by progress, and click a delve to create the next waypoint with TomTom or the native Retail waypoint system.

## Features

- Tracks all 10 Delver's Call - Midnight quests.
- Filters quests by Not Taken, In Progress, Completed, and Turned In.
- Creates TomTom or native game waypoints.
- Includes practical route steps through Silvermoon, Isle of Quel'Danas, Harandar, and Voidstorm.
- Adds known turn-in locations when available.
- Remembers selected filter, highlighted quest, and active route after reload.
- Optional autohide and hide-in-combat behavior.
- New default option: automatically stays hidden after reload/relog when your character is level 90 or higher. You can disable it in addon settings.

## Commands

| Command | Action |
| --- | --- |
| `/dcall` or `/dct` | Open/toggle the tracker |
| `/dcall settings` | Open addon settings |
| `/dcall show` | Show the panel |
| `/dcall hide` | Hide the panel |
| `/dcall combat enable\|disable` | Toggle hide in combat |
| `/dcall autohide enable\|disable` | Toggle mouseover autohide |

## Optional Dependency

TomTom is optional but recommended. Without TomTom, the addon will try to use the native Retail waypoint system.
